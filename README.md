# 🚗 Premium Car Rental Website

A responsive, modern car rental website built with **HTML**, **CSS**, and **JavaScript**, featuring animated UI, a swiper-based car selection interface, and a mobile-friendly navigation system.

# ✨ Features

- 🔥 Responsive design across all screen sizes
- 🚘 Dynamic car selection slider using **Swiper.js**
- 🧭 Smooth scroll and animated reveals using **ScrollReveal.js**
- 📱 Mobile navigation with a toggleable hamburger menu
- 📍 Location search, rental dates, and form layout


## 🔧 Technologies Used

- **HTML5** – Semantic structure
- **CSS3** – Flexbox, Grid, Animations
- **JavaScript** – DOM manipulation & interactivity
- [**Swiper.js**](https://swiperjs.com/) – Car selection slider
- [**ScrollReveal.js**](https://scrollrevealjs.org/) – Element animations
